# AGI Systems Tool Kit (STK) Level 1 and Level 2 Training + Certification
This repository contains a collection of my training exercises for **STK Level 1 - Beginner Tutorials** and **STK Level 2 - Advanced Tutorials** as well as my **Level 1 - STK Certified** and **Level 2 - STK Master Certified** certifications

**Tutorial Link**: https://help.agi.com/stk/index.htm#training/Day1Overview.htm?TocPath=Tutorials%2520and%2520Training%257CSTK%2520Level%25201%2520-%2520Beginner%2520Tutorials%257C_____0

**Certification Registration Link**: https://www.agi.com/training-and-certification#cert 

## Repository Format 
The repository is split into four main folders: STK Level 1 Tutorial, STK Level 2 Tutorial, STK Level 1 Certification, and STK Level 2 Certification

### STK Level 1 - Beginner Tutorials 
**[STK Level 1](./Level_1/STK_Level_1_Tutorial)**
- [Build Scenarios](./Level_1/STK_Level_1_Tutorial/STK_NewScenario) - Discusses how to open, save, interpret, and close a STK window
- [Objects and Properties](./Level_1/STK_Level_1_Tutorial/STK_Objects_Properties) - Teaches how to insert different kinds of objects and modify their properties in an STK scenario
- [Access Reports and Graphs](./Level_1/STK_Level_1_Tutorial/AccessReportsGraph) - Demonstrates how to use the Access tool and analyze the accesses through the Report & Graph Manager
- [Movies and Visual Data Files](./Level_1/STK_Level_1_Tutorial/STK_Movies_VDFs) - Explores creating a simple movie in STK and converting an STK scenario into a VDF
- [Introduction to Connect](./Level_1/STK_Level_1_Tutorial/STK_Connect) - Defines the Connect Command Library, Simple Connect Commands, and API Demo Utility


### STK Level 2 - Advanced Tutorials
**[STK Level 2](./Level_2/STK_Level_2_Tutorial)**  
- [Using Terrain, Chains, and Constellations](./Level_2/STK_Level_2_Tutorial/TerrainChainsConstellations) - Explores the application of local terrain files for analysis and the creation of a Constellation and Chain object
- [Customize Analysis with the Analysis Workbench](./Level_2/STK_Level_2_Tutorial/STK_AnalysisWorkbench) - Discusses the usage of the Analysis Workbench, Vector Geometry tool, Time tool, and Calculation tool
- [Compute Coverage Over Regions](./Level_2/STK_Level_2_Tutorial/STK_Coverage) - Teaches how to compute coverage globally or within a designated area
- [Introduction to the AzEl Mask Tool and Volumetrics](./Level_2/STK_Level_2_Tutorial/AzElMask_Volumetrics) - Discusses the usage of the AzEl Mask tool and Volumetric Analysis
- [Performing Trade Studies with ModelCenter](./Level_2/STK_Level_2_Tutorial/STK_ModelCenter) - Demonstrates the application of trade studies through the ModelCenter software
- [Introduction to Communications](./Level_2/STK_Level_2_Tutorial/STK_Communications) - Defines the Transmitter and Receiver object and how to use them to generate a Link Budget report for analysis
- [Introduction to Radar](./Level_2/STK_Level_2_Tutorial/STK_Radar) - Demonstrates the use of a radar and its probability of detection for different types of air-based target
- [Model Aircraft Missions with Aviator](./Level_2/STK_Level_2_Tutorial/STK_Aviator) - Teaches how to use STK's Aviator to define a flight route and procedure for an aircraft and track its payload requirement and fuel use
- [Introduction to the Advanced CAT Tool](./Level_2/STK_Level_2_Tutorial/STK_CAT) - Explores the usage of the Advanced CAT tool to determine the threat of collision between two objects
- [Design Trajectories with Astrogator](./Level_2/STK_Level_2_Tutorial/STK_Astrogator) - Explorers the capabilities of the Astrogator and defines the application of the Launch Vehicle object
